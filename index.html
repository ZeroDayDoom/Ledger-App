Gemini API key

Stored only in this browser's localStorage — it never leaves your machine except in direct calls you make to generativelanguage.googleapis.com. Clearing browser data or using another device means re-entering it.

Excel data

Import reads a workbook in the Ledger format (Settings / Expenses / Income / IOUs sheets) and replaces everything currently in the app with what's in the file.

Import is one-way — entries you add on the website only live in this browser's storage; your original Excel file on disk is never touched automatically (browsers can't write to your files for security reasons). Use Export any time to download a fresh .xlsx with everything currently in the app, in the same format — save it over your old file to keep them in sync.
